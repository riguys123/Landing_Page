Potencia y Simplicidad

Funcionalidades Diseñadas para la Máxima Eficiencia

Cada módulo ha sido cuidadosamente construido para proporcionar una administración intuitiva, rápida y sin complejidades innecesarias.

Gestión de Productos & Categorías

Operaciones CRUD completas (Crear, Leer, Actualizar, Eliminar) con relaciones relacionales Many-to-One fluidas y asignación jerárquica instantánea.

Interfaz Rápida y Dinámica

Vistas optimizadas renderizadas con el motor Thymeleaf e integradas con componentes reactivos de Bootstrap 5 para una experiencia ágil y adaptable.

Persistencia de Datos Segura

Integración con SQLite mediante Spring Data JPA e Hibernate. Almacenamiento local ligero, sin necesidad de configuraciones de servidor complejas.

Filtrado y Búsqueda Multicriterio

Localización inmediata de productos por nombre, código interno, rango de precios o categoría asignada con respuestas instantáneas.

Arquitectura MVC Escalable

Separación limpia de responsabilidades en capas: Controladores, Servicios de Negocio, Repositorios JPA y Modelos de Dominio bien definidos.

Control de Stock & Validaciones

Validación de formularios con Hibernate Validator (Jakarta Bean Validation) e indicadores automáticos para productos en niveles de stock crítico.

Demostración Interactiva del Sistema

Este proyecto implementa una arquitectura modelo-vista-controlador completa. A continuación se presentan las secciones clave del panel de control:

Control Total de Catálogo

Formulario con validación en servidor para nombre, precio unitario, existencias mínimas y asociación directa con una categoría registrada.

Incluye alertas visuales automáticas cuando el stock es menor a 5 unidades.
Taxonomía y Agrupación

Permite organizar productos de manera estructurada. Las categorías mantienen integridad referencial, impidiendo eliminación accidental de categorías con productos asignados.

Integridad referencial asegurada con anotaciones JPA @ManyToOne y @OneToMany.
Almacenamiento Local Portable

El archivo de base de datos SQLite se genera automáticamente en la raíz del proyecto. No se requiere instalación ni configuración de servicios MySQL o PostgreSQL externos.

Ejecución con un solo comando: ./mvnw spring-boot:run
¿Deseas desplegar el proyecto localmente?

Requisitos: Java JDK 17+ instalado y Maven (o utilizar el wrapper incluido).

$ git clone https://github.com/tu-usuario/proyecto-inventario.git
$ cd proyecto-inventario
$ ./mvnw spring-boot:run
